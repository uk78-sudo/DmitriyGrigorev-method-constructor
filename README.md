# DmitriyGrigorev-method-constructor
# Электронный конструктор методических указаний

## Описание
Электронный конструктор для формирования методических указаний к рейтинговым работам в ЧОУ ВО «Московский университет им. С.Ю. Витте». Система позволяет автоматизировать процесс создания методических указаний, обеспечить их соответствие требованиям образовательных стандартов и сократить временные затраты преподавателей на подготовку документации.

## Возможности
- Создание методических указаний на основе шаблонов
- Выбор компетенций из справочника в соответствии с ФГОС ВО
- Выбор литературы из электронной библиотечной системы университета
- Экспорт методических указаний в форматы PDF и DOCX
- Интеграция с системой дистанционного обучения Moodle
- Интеграция с электронной библиотечной системой
- Интеграция с системой учета контингента 1С:Университет ПРОФ

## Технологии
- Frontend: React.js
- Backend: Laravel (PHP)
- База данных: MySQL
- Аутентификация: JWT

## Установка и запуск
1. Клонировать репозиторий
git clone https://github.com/DmitriyGrigorev/method-constructor.git

2. Установить зависимости PHP
composer install

3. Установить зависимости JavaScript
npm install

4. Настроить файл окружения
cp .env.example .env
php artisan key

5. Настроить подключение к базе данных в файле .env

6. Выполнить миграции и заполнить базу данных начальными данными
php artisan migrate --seed

7. Запустить сервер разработки
php artisan serve
npm run dev
